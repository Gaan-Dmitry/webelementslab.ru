# Обзор проекта WebElementsLab

Дата обзора: 2026-04-14

## Что это за сайт
WebElementsLab — библиотека пользовательских сниппетов (HTML/CSS/JS) с каталогом, карточками сниппетов, авторизацией, избранным и личным профилем.

## Текущая архитектура
- Стек: PHP + MySQL + vanilla JS + CSS.
- Главная страница рендерится в `index.php`, карточки подгружаются через AJAX (`handlers/load_snippets.php`) и строятся на клиенте (`assets/js/main.js`).
- Страницы вынесены в `pages/`, общие элементы — в `templates/`.

## Сильные стороны
- Используются подготовленные SQL-запросы (PDO) в большинстве мест.
- Есть базовая защита входа от перебора попыток.
- Данные в HTML обычно экранируются через `htmlspecialchars`.
- Реализован удобный UX: бесконечная лента, шаринг, избранное.

## Риски и проблемы
1. **Критично**: в `includes/db.php` хранится реальный логин/пароль БД в открытом виде.
2. **Критично**: отсутствует CSRF-защита в формах и POST-хендлерах.
3. **Высокий риск**: пользовательский HTML/CSS/JS исполняется в `iframe srcdoc` без sandbox на главной и в карточке — допустимо для «песочницы», но опасно без ограничений.
4. **Средний риск**: `pages/check_field.php` подставляет имя поля в SQL (хоть и через whitelist, но лучше делать явную ветвизацию по полям).
5. **Надёжность**: в репозитории нет схемы БД/миграций и `.env.example`, развёртывание зависит от ручных шагов.

## Рекомендации (приоритет)
1. Срочно вынести доступы БД в переменные окружения (`.env`) и заменить секреты.
2. Добавить CSRF-токены для всех изменений состояния (логин, регистрация, избранное, создание/редактирование).
3. Для предпросмотра сниппетов включить ограничения `iframe sandbox` и/или отдельный изолированный домен для пользовательского кода.
4. Добавить SQL-миграции и инструкцию первичного развертывания с минимальным seed.
5. Включить централизованное логирование ошибок вместо `display_errors=1`.

## Итог
Проект жизнеспособен как MVP-каталог сниппетов и уже имеет основные пользовательские сценарии. Для продакшн-уровня нужны обязательные улучшения безопасности и процесса деплоя.
