# WebElementsLab.ru

![WebElementsLab Logo](assets/img/logo512.png)

**WebElementsLab** — это библиотека готовых сниппетов, UI-элементов и компонентов на HTML, CSS и JavaScript для быстрого прототипирования и разработки современных веб-проектов.

## Требования
- PHP 7.4 или выше
- MySQL 5.7 или выше
- Веб-сервер (Apache/Nginx)

## Возможности
- Большой каталог сниппетов и UI-элементов
- Быстрый поиск и фильтрация
- Система избранного
- Бесконечная лента свежих решений
- Поддержка авторизации и регистрации
- Адаптивный дизайн

## Структура проекта
- `index.php` — главная страница
- `assets/` — стили, скрипты, изображения
- `handlers/` — обработчики запросов
  - `load_snippets.php` — загрузка сниппетов
  - `login_handler.php` — обработка входа
  - `password_reset_handler.php` — сброс пароля
  - `toggle_fav.php` — добавление в избранное
- `includes/` — подключаемые PHP-файлы
  - `db.php` — конфигурация базы данных
- `pages/` — страницы приложения
  - `card.php` — страница сниппета
  - `check_field.php` — проверка полей формы
  - `edit_or_create_card.php` — создание/редактирование сниппета
  - `favorites.php` — избранные сниппеты
  - `guide.php` — руководство
  - `login.php` — страница входа
  - `logout.php` — выход из системы
  - `password_reset.php` — сброс пароля
  - `privacy.php` — политика конфиденциальности
  - `profile.php` — профиль пользователя
  - `random_snippet.php` — случайный сниппет
  - `register.php` — регистрация
  - `settings.php` — настройки
- `templates/` — шаблоны header/footer
  - `header.php` — верхняя часть страницы
  - `footer.php` — нижняя часть страницы
- `uploads/` — загруженные файлы пользователей

## Установка и настройка

1. Скопируйте файлы проекта в директорию веб-сервера
2. Создайте базу данных MySQL
3. Настройте подключение к базе данных в файле `includes/db.php`
4. Создайте необходимые таблицы в базе данных (описание структуры таблиц отсутствует в проекте - возможно, они создаются автоматически при первом запуске)
5. Установите права на запись для директории `uploads/`
6. Запустите веб-сервер и откройте сайт в браузере
